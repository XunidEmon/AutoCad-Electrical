## 🚀 How to Use

1. **Visit the app:** [Live Demo](https://xunidemon.github.io/AutoCad-Electrical/)
2. **Select room type** (Bedroom, Kitchen, etc.)
3. **Enter room dimensions** (feet + inches)
4. **Set mounting height** (default: 2.0 m)
5. Click **⚡ Calculate**
6. Get instant results:
   - 💡 Lights required
   - 🌀 Fans required
   - 🔌 Sockets required
   - ⚡ Total load & current
   - 🧵 Wire size & MCB
7. **💾 Save** to history or **📄 Download PDF**
